# QuickDic 국내 사전 원본 (정리본)

`stdict-clean.zip` — 국립국어원 「표준국어대사전」 전체 내려받기(JSON, 2026-10-12 기준)를
QuickDic 이 쓰는 항목만 남겨 정리한 파일입니다. 매주 '사전 데이터 만들기' 워크플로가 이 브랜치에서 가져다 씁니다.

- 출처: 국립국어원 표준국어대사전 https://stdict.korean.go.kr
- 라이선스: 크리에이티브 커먼즈 저작자표시-동일조건변경허락 2.0 대한민국 (CC BY-SA 2.0 KR)
- 출판물·신문 등에서 인용한 예문(출처가 달린 예문)과 사진·소리 등 미디어 링크는 라이선스 대상이 아니므로 뺐습니다.
- 만든 방법: `python tools/clean_kodict.py 원본.zip stdict-clean.zip` (main 브랜치의 도구)

새 데이터로 바꿀 때는 이 파일만 바꿔 올리면 됩니다.
